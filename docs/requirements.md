# 要件定義 — GLB Converter Tool

## 1. プロダクト概要

OBJ / FBX 形式の 3D モデルファイルをブラウザからアップロードし、GLB 形式に変換してダウンロードする Web ツール。

---

## 2. ユーザーストーリー

| # | ストーリー |
|---|-----------|
| US-01 | ユーザーは OBJ ファイル（および付属の MTL ファイル）をアップロードして GLB に変換できる |
| US-02 | ユーザーは FBX ファイルをアップロードして GLB に変換できる |
| US-03 | ユーザーは変換後の GLB ファイルをダウンロードできる |
| US-04 | ユーザーは変換前に 3D モデルをプレビューできる（Nice to have） |
| US-05 | 変換に失敗した場合、ユーザーはわかりやすいエラーメッセージを受け取れる |

---

## 3. 機能要件

### 3.1 ファイルアップロード

- 対応入力形式: `.obj`（+ `.mtl`）、`.fbx`
- アップロード方法: ドラッグ & ドロップ、またはファイル選択ダイアログ
- ファイルサイズ上限: TBD（例: 100MB）
- 複数ファイル同時アップロード: OBJ + MTL のペアに対応

### 3.2 変換処理

- OBJ → GLB 変換
- FBX → GLB 変換
- テクスチャ・マテリアル情報の保持
- 変換処理はサーバーサイドで実行（クライアント負荷を避けるため）

### 3.3 ダウンロード

- 変換完了後、`.glb` ファイルをダウンロードリンクとして提供
- ファイル名は入力ファイル名をベースに自動生成（例: `model.obj` → `model.glb`）

### 3.4 エラーハンドリング

- 非対応ファイル形式のアップロード時にエラー表示
- ファイルサイズ超過時にエラー表示
- 変換失敗時にエラー詳細を表示

## 5. 技術スタック（候補）

### フロントエンド

| 候補 | 備考 |
|------|------|
| React + TypeScript | コンポーネント管理がしやすい |
| Vanilla HTML/JS | シンプルな構成で十分な場合 |

### バックエンド

| 候補 | 備考 |
|------|------|
| Python + FastAPI | trimesh / pygltflib / Blender Python API が使えて変換処理が強力 |
| Node.js | three.js エコシステムと親和性が高い |

### 変換ライブラリ候補

| ライブラリ | 対応形式 | 備考 |
|-----------|---------|------|
| trimesh (Python) | OBJ → GLB | 軽量・扱いやすい |
| pygltflib (Python) | GLB 生成 | GLB/GLTF 特化 |
| Blender (bpy) | OBJ / FBX → GLB | 最も高精度だが環境構築が重い |
| assimp | OBJ / FBX → GLTF | C++ ベース、多形式対応 |
